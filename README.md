# jayys11

Jay影视 —— 暗色现代风格的 PHP 影视网站，适配 InfinityFree 免费服务器，兼容 PHP 7.4 - 8.x + MySQL。

## 快速部署

1. 上传全部文件到服务器（或本仓库克隆到网站目录）
2. 首次访问任意页面自动跳转 `install.php` 安装向导
3. 填写数据库信息与管理员账号，自动建表、生成配置、销毁安装入口
4. 登录后台 `admin/index.php` →「网站设置」填写 TMDB API Key 即可出片

默认后台账号：`杰同学` / `101113`（可在安装向导中自定义）

## 功能一览

- TMDB 元数据 + 图片代理（api.tmdb.org / images.tmdb.org）
- 播放源管理：多源增删改、默认源设置；真实 m3u8 直链 urlencode 后拼接解析播放器 iframe 播放
- 用户体系：邮箱验证码注册（163 SMTP）、登录、封禁（自动邮件通知）
- 观看历史 / 我的收藏 / 自定义头像 / 反馈互动（点赞、回复、管理员置顶、>3 条折叠）
- 网站公告（仅首页弹窗、Cookie 免打扰、新公告失效重弹）、全站主题色自定义
- 纯 CSS 图标，零外部图标库，三端自适应，流畅过渡动画

## 目录结构

```
admin/      管理后台（仪表盘/用户/播放源/邮件/公告/设置/反馈）
assets/     样式与脚本（纯CSS图标库）
includes/   核心库（init/functions/smtp/tmdb/source）
uploads/    用户头像
install.php 安装向导（安装后自毁）
```
